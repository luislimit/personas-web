# Incremental 01c — contexto en cabecera

Ajuste de UX solicitado para el shell administrativo.

## Cambios

- Se elimina el botón independiente `Cambiar contexto`.
- La cabecera muestra `Conectado a:`.
- Si la cuenta dispone de varios contextos, aparece un desplegable para cambiar de contexto directamente.
- Si solo existe un contexto, se muestra como texto y no como una acción innecesaria.
- Bajo el contexto se mantiene, de forma discreta, el rol y el alcance activos.
- La pantalla de Inicio deja de mostrar una tarjeta técnica con el contexto y los permisos.
- Inicio pasa a ser una portada más funcional y orientada a módulos.

No requiere cambios de backend ni de base de datos.
